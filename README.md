Based on FlatCAM: 
2D Computer-Aided PCB Manufacturing by (c) 2014-2018 Juan Pablo Caram

FlatCAM is a program for preparing CNC jobs for making PCBs on a CNC router.
Among other things, it can take a Gerber file generated by your favorite PCB
CAD program, and create G-Code for Isolation routing.

## Running from Sources

1. Git clone the project

```bash
git clone https://github.com/mekatrol/flatcam
cd flatcam
git checkout develop
```

2. Install packages

```bash
sudo apt update
sudo apt install -y \
  git make build-essential \
  python3 python3-venv python3-dev python3-pip \
  pkg-config \
  libxcb-cursor0 libxkbcommon-x11-0 \
  libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-randr0 libxcb-render-util0 \
  libxcb-shape0 libxcb-xinerama0 libxcb-xkb1 \
  python3-cairo \
  libcairo2-dev \
  libgeos-dev gdal-bin libgdal-dev python3-gdal
```

3. Create python environment

```bash
python3 -m venv .venv --system-site-packages
source .venv/bin/activate
python -m pip install -U pip setuptools wheel
pip install -r requirements.txt
```

> Safely ignore error  
ERROR: pip's dependency resolver does not currently take into account all the packages that are installed. This behaviour is the source of the following dependency conflicts.
yt-dlp 2024.4.9 requires websockets>=12.0, but you have websockets 10.4 which is incompatible.


4. Launch FlatCAM

```bash
python flatcam.py
```
